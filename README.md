# Tales Of Austia

## Game Description

Tales Of Austia is a simple graphics project created using the **iGraphics** library in C. The project demonstrates basic graphics programming concepts like drawing shapes, handling user input, and simple animations.


## Features
- One main character with many interactable npc characters.
- Story based progression.
- Health bars, basic animations, kept minimal till end.
- Keyboard controls for attacking and movement.
- Simple Opponent attacks and patterns for fair gameplay.


## Project Details
IDE: Visual studio 2010/2013

Language: C,C++.

Platform : Windows PC.

Genre : 2D, action, mystery, rpg, adventure, metaphoric


## How to Run the Project

Make sure you have the following installed:
- **Visual Studio 2013**
- **MinGW Compiler** (if needed)
- **iGraphics Library** (included in this repository)
Clone this repo and then,
Open the project in Visual Studio 2013
- Open Visual Studio 2013.
- Go to File → Open → Project/Solution.
- Locate and select the .sln file from the cloned repository.
- Click Build → Build Solution
- Run the program by clicking Debug → Start Without Debugging


## How to Play

### **Controls**
| Player       | Move Left | Move Right | Move Up | Move Down |
| ------------ | --------- | ---------- | ------- | --------- |
| **Player 1** | `A`       | `D`        | `W`     | `S`       |

#### **Additional:**
`Space` - for Attack/Jump according to the co-responding challenge.

#### **DevKeys:**
`B` - to toggle Collision borders
`N` - to skip through current scene/floor to move to the next.


### **Game Rules**

- The player has to explore floors and progress in the game through challenges
- Should NOT use any dev keys to finish the game.
